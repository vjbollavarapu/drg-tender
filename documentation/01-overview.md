# DRG Platform — Cloud & Platform Engineering Overview

## Purpose
This repository defines the technical responsibilities, architecture, and operational model required to successfully deploy and operate the National DRG System on MyGovCloud.

## Context

- Cloud Environment: MyGovCloud (AWS-backed)
- Application Owner: Casemix Solutions Sdn Bhd
- Platform & Operations: QK Prima (with VCS support)

## Key Principle

Cloud infrastructure alone does not ensure system success.

A complete delivery requires:
- Architecture
- Integration
- Data migration
- Security
- Observability
- Operations

## Objective

To ensure the DRG system operates as:
- Secure
- Scalable
- Reliable
- Compliant
- Observable
- Supportable
