# 📊 RACI Matrix — DRG Platform Delivery

## 🎯 Purpose

Define clear responsibility assignments across AWS, Casemix, and QK Prima.

---

## 🧠 Legend

- R = Responsible (does the work)
- A = Accountable (owns outcome)
- C = Consulted
- I = Informed

---

| Activity | AWS | Casemix | QK Prima |
|---------|-----|---------|----------|
| Infrastructure provisioning | R | I | C |
| Application development | I | R | C |
| Platform architecture | I | C | A/R |
| Data migration | I | C | A/R |
| Integration (SMRP, MyGDX) | I | C | A/R |
| Security implementation | C | C | A/R |
| Monitoring setup | C | I | A/R |
| Incident response | I | I | A/R |
| SLA management | I | I | A/R |
| Disaster recovery | C | I | A/R |
| Performance tuning | I | C | A/R |
| Cost governance | C | I | A/R |

---

## 🎯 Key Insight

> QK Prima is accountable for all platform-level outcomes.
