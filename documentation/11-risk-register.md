# Risk Register

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Data migration failure | High | Validation + testing |
| Integration failure | High | Retry + monitoring |
| Security breach | Critical | Encryption + RBAC |
| Performance issues | High | Load testing |
| SLA breach | High | Monitoring + ops |

---

## Key Principle

All risks must have:
- Owner
- Mitigation plan
- Monitoring
