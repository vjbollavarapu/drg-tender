# Responsibility Matrix
## DRG Solution Partner vs AWS Cloud Platform Partner

| Area | DRG Solution Partner | AWS Cloud Platform Partner |
|---|---|---|
| DRG business logic | Primary | Support only where platform-impacting |
| Clinical coding rules | Primary | Out of scope |
| Grouper logic | Primary | Out of scope |
| Costing formulae | Primary | Out of scope |
| Functional reporting definitions | Primary | Support for runtime/performance only |
| Application codebase | Primary | Support for deployment/runtime integration |
| AWS target architecture | Consulted | Primary |
| Cloud environments | Consulted | Primary |
| Network security design | Consulted | Primary |
| Runtime operations | Consulted | Primary |
| CI/CD pipelines | Shared | Primary |
| Secrets / encryption / IAM | Shared | Primary |
| Monitoring / alerting | Shared | Primary |
| Backup / recovery | Shared | Primary |
| Production incident platform triage | Consulted | Primary |
| Application bug resolution | Primary | Consulted |
| Capacity / scaling engineering | Consulted | Primary |
| Cost governance on AWS | Consulted | Primary |
| Helpdesk platform incident support | Shared | Primary for platform scope |
| UAT/PAT/FAT environment readiness | Shared | Primary for platform scope |
| Release governance | Shared | Primary for platform controls |
